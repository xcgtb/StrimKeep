## 实机验收顺序

1. 保留现有数据、授权和部署配置，按 SOURCE_BUNDLE.md 更新源码并构建新镜像；仅复制源码不会更新容器。新增加的代理依赖必须随镜像安装，不能只替换 Python 文件。
2. 初始保持频道暂停，检查服务连接中的代理。在公开网页预览或「读取并检查」中确认能看到实际消息、连接方式与耗时。私有频道使用有权限的用户会话。
3. 用一条有权限处理的有效分享验证转存；明确勾选后续整理时核对接收目录、归档目录、命名与 STRM 输出开关。任务链分别检查实际回执，Emby 入库另看确认。
4. 启用单个频道，观察多轮轮询期间 Web 登录、日志和健康检查。需要时模拟网络断开，确认后台报错退避且 Web 可用，再逐步增加频道。
5. 历史覆盖不完整时不要为了消除报错直接重置位置。先检查范围；只有明确接受略过未接收消息时，才确认位置恢复。
