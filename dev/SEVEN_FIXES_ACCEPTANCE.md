基线：`xcgtb/StrimKeep` main，`c84c1d64d68d28be8c02dc4ca418ce5e04b65472`，精确标签 `v1.5.18`。本包是该基线之上的完整修复源码，包含 Vue 源码、重新编译的 static、Python 后端和回归测试。变更记在 CHANGELOG「未发布」；未推送仓库、未创建或移动发布标签，也未更新 NAS 容器。

## 修复对应

| 问题 | 修复与验证 |
| --- | --- |
| STRM 定时同步未创建任务 | 按真实 `{id,name}` 目录对象读取 ID，兼容历史数字格式；真实目录保存→Cron tick→SQLite 任务验证通过。同账号同目录已有排队或执行中的 sync 时复用已有任务，本轮排期记为已检查，避免积压重复扫描。 |
| 断开账号残留 TG 开关 | 事务内删除服务凭据、目录缓存、频道和游标，未派发接收记录写明断开原因；任务历史保留。互斥查询与消息捕获排除历史孤儿账号；消息加密后、插入前再核对账号，防止并发断开后留下新接收记录。 |
| 长任务阻塞频道调度 | 执行槽等待期间每两秒继续频道读取、资源派发、维护排期及自动规则；远端写入仍串行排队。测试覆盖后台调度发生一次异常后继续运行，且不会启动第二个写任务。 |
| Cookie 删源说明错误 | 账号状态、功能搜索、八维入口及删除开关统一说明 Cookie 按文件 ID 删源能力；OpenAPI 独立展示。测试覆盖只有 Cookie、没有 OpenAPI 的账号。未改删除执行权限、身份核验及确认流程。 |
| STRM 主页面漏配置 | 主页面增加 Cron、时区及探测拦截，沿用原设置 API、确认保存与局部字段提交；不改写其他模块目录。首次开启执行一轮、后续遵循 Cron，页面已说明。 |
| Git 换行处理图片 | 前端文本自动识别并规范 LF；图片和字体禁用文本转换。四个实际二进制资产的 Git 暂存及检出逐字节一致，图片解码与源文件/构建产物字节一致。 |
| 历史大版本号影响构建 | 未打新标签的提交按第一父提交历史取最近正式发布，支持附注与轻量标签；合并侧分支上的版本标签不覆盖主线。覆盖历史 v1.12.11 → v1.5.18 → 未标记修复提交场景；保留旧标签。精确标签构建沿用该标签。 |
| 手机播放引用框越界 | 播放校验卡片采用可收缩单列轨道，select/input/按钮限制在卡片内，长文本可换行。320、390、430px 下，超长文件名、内外网长链接及核验结果均无水平溢出。 |

同库多版本去重、残次品判断、跨库择优、七维/八维决策及单库独有季保护未调整。

## 在飞牛工作区覆盖

本包根目录直接包含 `app/`、`frontend/`、`static/`、`docs/` 等完整源码，适合覆盖 `/vol1/1000/git/StrimKeep`，不要覆盖实际运行数据。

前端已重新构建。覆盖现有工作区时，旧版本的哈希资源也应移除：`dev/obsolete-assets-after-v1.5.18.txt` 列出了本次移除的旧 `static/assets/` 文件；这些路径不属于新包资产。不要删除其他源码或运行文件。也可通过在工作区重新执行 `npm --prefix frontend run build` 让 Vite 重建并清理 static。

发布时按新的、未使用过的版本写入正式 CHANGELOG，再提交与打新标签；本包不预占版本号、不覆盖 v1.5.18。
