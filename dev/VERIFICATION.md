生产验收环境只安装 `requirements.txt`，没有安装 `httpx` 或 pytest。所有隔离脚本使用临时状态和临时媒体；未访问真实 NAS/115 资源，也未发送消息。真实 HTTP 验证使用本地 uvicorn 子进程，另验证配置保存后重启读取 SQL 最新值，旧 JSON 保持原值。

源码包含公共镜像 YML、应用、前端、GitHub 工作流、README、版本日志、架构及部署说明；测试和维护工具统一在 `dev/`。未包含过往阶段报告和工作进度表。`MANIFEST.sha256` 记录每个源码文件校验值。

## 部署验收仍需完成

- 当前本地环境没有 Docker daemon，未声称 Docker 镜像构建或 amd64/arm64 发布已通过。GitHub 工作流会构建生产镜像并运行无网络的启动验收。
- DOM 替身不等于真实手机/桌面视觉验收；浏览器和反代应在部署后确认。
- NAS/CD2 挂载、115 实际删除及大库资源占用需要真实部署验证。
- 项目、服务、数据库、Cookie 和海报缓存均已改名。旧部署要沿用数据时，先按部署说明离线迁移数据库名称，不能直接覆盖后启动。
