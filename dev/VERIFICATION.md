## 部署验收仍需完成

- 当前本地环境没有 Docker daemon，未声称 Docker 镜像构建或 amd64/arm64 发布已通过。GitHub 工作流会构建生产镜像并运行无网络的启动验收。
- DOM 替身不等于真实手机/桌面视觉验收；浏览器和反代应在部署后确认。
- NAS/CD2 挂载、115 实际删除及大库资源占用需要真实部署验证。
- 项目、服务、数据库、Cookie 和海报缓存均已改名。旧部署要沿用数据时，先按部署说明离线迁移数据库名称，不能直接覆盖后启动。

## 2026-10-10：影视探索无限滚动优化

基线提交：`14d4dfb`；开发分支：`feat/explore-infinite-scroll`。源码与 CHANGELOG 已统一为 1.0.2。应用和 CI 从 `app/version.py` 读取版本；Dockerfile 不重复定义版本，开发 Compose 使用固定的 `strimkeep:local`。公共部署 Compose 继续使用 latest。

- TMDB 每次请求一页（最多 20 条），不再等待两页合并；分页支持到 500 页。缓存键增加协议标记，旧合并分页缓存不会造成跳页。
- 接近底部自动追加，下一页预取并预热少量海报；保留跨页去重、最后一页余数和失败后的手动重试。
- 可见结果到达后立即释放加载锁，过期探索缓存和片库状态由独立任务刷新；集数标记更新不重建海报节点。
- 切换筛选或离开时中止过时请求。取消追加请求后恢复最后成功页，返回同一条件时复用卡片和滚动位置。
- 首屏加入支持深浅主题和减少动画偏好的骨架占位。启动不等待订阅列表；提交订阅前仍等待完整列表，避免覆盖已有订阅，成功后仅更新按钮。
- 切换电影/剧集时先重置不适用的题材，再发送请求。
- 补充 main 推送自动构建 latest；正式版本号镜像仅在版本标签发布时更新。支持“覆盖 Git 工作区 → 推送 GitHub → 等待构建成功 → 原部署目录 pull/up”的更新流程。

验证：Python 3.12.14 / Node 24.19.0；`ENABLE_CD2_WATCHDOG=0 pytest dev/tests/ -q`：682 项通过，1 条第三方弃用提示。前端语法及 20 组交互回归通过；静态检查与发布边界检查通过。测试使用临时数据及服务替身，没有访问实际媒体或发送通知。
