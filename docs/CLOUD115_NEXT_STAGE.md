# 115 生产完善与身份治理阶段记录

基线：远程 main `6da8a83`，发布 `v1.3.1`。2026-10-14 已核实 Actions 回归、生产镜像、历史数据库/HTTP 检查、多架构镜像发布均成功；未检查用户 NAS 运行容器。

分支：`feature/115-production-governance`。本阶段尚未发布，没有确定新版本号，不改已有标签。

## 实施目标

1. 核实并接入本应用的 OpenAPI PKCE 扫码、加密令牌存储、续期与授权状态；没有自有 AppID 时仍可完整使用 Cookie 工作流，不借用 SDK 默认第三方 AppID。普通用户不手填 UID。
2. 以接口实际能力选择授权：Cookie 保留分享转存与有明确重名策略的整理；Open 支持官方文件查询/播放与已核实的删除接口。不凭假设替换写入接口。
3. 完善命名配置、任务进度、转存超时核实后的后续整理入口。
4. 将本项目已绑定 STRM 的来源信息加入治理预览；按账号 UID、目标文件 ID 与内容指纹处理源文件删除，确认回执后才清理 STRM。分享库仍只清理 NAS；旧未绑定文件保持原有流程，不自动猜绑定。
5. 验证同名文件、授权轮换、中断写入、删除超时和权限失败，运行全量兼容与真实浏览器检查后打包交付。

## 事实与待核实项

- SDK 固定版本仍为 p115client 0.0.9.7.2；已读取 PKCE 设备码、换令牌、刷新令牌、Open user/info、file query、ufile/delete 和回收站方法。
- SDK 默认 Open AppID 属于第三方，不能用作本应用身份。必须配置本应用自有 ID。
- 刷新令牌是轮换操作：请求前持久化状态，网络结果不明时禁止重用旧 refresh token。SDK 自动刷新将由业务层持久化续期代替。
- 文件 ID 与作品身份是两层记录。TMDB/type/季集号用于作品配对；UID/file ID/sha1 用于准确定位和删除物理来源。
- 真正扫码、账号权限、CDN 与 Emby 客户端仍需用户当前部署验证；本地隔离通过不等于真实账号验收。
- 本阶段没有实际删除用户网盘文件的授权素材或可用账号，因此所有故障注入使用隔离服务。


## 已完成的代码

| 分类 | 改动 | 实际效果 |
| --- | --- | --- |
| 授权 | accounts/open115/credentials | 自有 AppID 的 PKCE 扫码；按 UID 合并两种授权；加密保存轮换令牌，状态先落盘，未知结果要求重新扫码 |
| 整理 | recognition/settings/workflow | 三种命名样式、自定义分类目录；作品目录保留 TMDB；只绑定能唯一归属的视频附属文件 |
| 任务 | jobs/store/工作台 | 持久化数量与阶段；超时转存核实后只队列一次后续整理，不重发分享接收 |
| 治理 | cloud/governance/cloud_bridge/plan_guard | 来源快照加入原治理计划、单片和批量确认；按物理文件 ID 校验，源码接口共用原任务互斥 |
| 删除 | wash/cloud_deletions | 先持久化单文件意图，再调用官方接口；结果确认后删除 STRM，执行中被替换的 NAS 内容仍保留 |
| 恢复 | 工作台 STRM 页及 API | 查看来源与步骤；只读核实，不重发；重置仅针对明确拒绝的请求，且继续保留部分组已验证的删除回执 |
| 兼容 | 原配置/SQLite/CLI | 七维比较规则不变；未登记文件沿用挂载删除；分享库即使账号断开也仅清理 NAS |

官方删除默认关闭。没有自有 AppID 或权限时可使用 Cookie 转存、整理、STRM 和播放；不能宣称已完成官方删除的真实账号验收。回收站若不提供精确物理文件 ID，超时请求保持待核实，绝不靠文件名猜成功。v1.3.1 的旧资产没有云端附属文件清单，后续完整同步可登记唯一归属的清单，未登记附属文件不删除。

本项目生成的身份并不自动解决所有媒体识别歧义：TMDB 匹配仍需识别预览/修正；它解决的是已确定来源后的物理文件定位。第三方 STRM 的旧库身份迁移另做，不从路径自动认领。

## 应用与发布

源码包以远程 v1.3.1 main 为基线，覆盖 Git 工作区中的应用文件，不能覆盖部署目录的数据。发布号尚未指定：先审查未发布日志，再为新版本创建新的不可变标签，构建通过后用户继续拉取 `latest`。不要复用 v1.3.1 或仅推 main 就认为镜像已更新。

真实联调顺序：设备扫码 → 少量测试分享转存 → 预览识别 → 真实整理 → STRM/NFO/字幕 → 播放和 Emby 反代；再配置本应用 OpenAPI 权限并扫码 → 开启官方删除 → 预览来源 ID → 确认一个不再需要的本地测试副本 → 核对源文件及 NAS 引用。真实结果应另外记录，不能将自动测试改写为 NAS 验收成功。
