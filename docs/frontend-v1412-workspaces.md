# 1.4.12 前端模块整合与功能对照

## 基线与范围

基于 `origin/main` / `19fab22ec7284eb7ea2bb4a05fabe8064fbf9e31`（v1.4.11 对应源码），整合本次上传的 source-first 侧栏补丁。截图仅用于导航结构和深色外观参考；实际页面使用 Vue 3 和真实后端 API，不接入演示接口。

本轮后端 `app/` 与数据库结构未修改。当前成果是前端整合候选，不表示已在 NAS 发布，也不表示所有第三方服务的真实自动化均已验收。未推送 main、未创建标签、未重启用户容器。

只有“我的网盘”可以展开，其余九项直接打开所属模块。

## 已修正的功能缺口与交互

| 项目 | 变化 | 后端对应能力 |
| --- | --- | --- |
| 一键资源接收 | 补上混合链接直接提交；确认后携带账号、目录版本、去重提交标识；原预览流程保留 | `POST /api/cloud/resources/receive` |
| 统一待整理目录 | 选一次目录，可把 source/transfer/magnet/ed2k/instant/bot 设为同一草稿，保存后生效；不改归档、未识别和频道独立目录 | `GET/POST /api/cloud/accounts/{account_id}/directories` |
| 接收目标可见 | 输入链接前显示 115 分享、磁力、ed2k、秒传各自已保存目录；按已保存接收策略初始化自动整理开关 | directories / receiving |
| 离线记录 | 账号加载完成后自动读取；切换账号重新读；移除/修改 tab 参数同步页面；显示加载、空列表、失败状态 | `GET /api/cloud/resources/offline` |
| 功能搜索 | 功能目录与侧栏分开维护，恢复命名、八维、自动整理、机器人、免转存和入库核验等搜索入口 | Vue 路由及现有业务 API |
| 模板页配置缺失 | 重命名、电影/剧集目录名、ffprobe、探测失败策略、未识别处理与空目录清理并入命名页 | `POST /api/cloud/settings`，只保存更改字段 |
| STRM 生成来源 | 自动读取已保存的 STRM 同步来源；普通刷新不会覆盖当前手选目录 | directories / strm sync |
| 技术信息展示 | 状态和原因优先；指纹、校验值、内部编号与配置版本可在“技术详情”展开，不删除安全核验依据 | 只调整显示，不改后端数据 |
| 任务类别 | 补上资源接收、频道、STRM 发布、分类目录等中文名称，列表不再用内部任务编号占据主信息 | 既有任务 API |

既有 Cookie/扫码/官方授权、账号维护、频道历史读取、TMDB 识别修正、七维与八维独立配置、治理确认、源删除回执、Emby 重试、多连接、追更、晨报、日志导出、外部资源搜索/订阅/转存能力继续保留。

## 不能当作本轮新增的后端能力

- 分享免转存仍调用 v1.4.11 的分享预览和 STRM 生成接口，按现有命名分类规则直接生成正式分享库；尚未新增“分享待整理→八维洗版→分享整理后”的持久化流水线。
- 磁力/ed2k 的任务被 115 接收不等于下载完成；下载后的接续需要配置既有自动整理扫描计划。
- 统一目录草稿不等于一键配置了所有自动化规则。归档目标、未识别目录、扫描计划、STRM 输出、Emby 连接和通知仍需有效配置。
- 没有在真实 NAS/115/Emby/Telegram 上执行转存、移动、洗版删除或发送通知；隔离测试不能证明用户生产环境端到端已通。
