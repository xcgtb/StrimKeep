### Cloudflare 拦截的 RSS 可手动导入

- 自动来源 → RSS 订阅新增「粘贴 RSS 内容导入」：浏览器打开 RSS 后复制全部 XML，粘贴到 StrimKeep 即可解析入队。
- 用于 re0 这类程序端返回 Cloudflare 403 的源；不绕过验证，也不保存浏览器 Cookie。
- 新增 `POST /api/v1/resources/feeds/import`，支持 RSS 2.0 / Atom 内容、目标目录和落盘后整理开关。
- 导入内容仍按原规则去重，重复资源不会重复提交。
