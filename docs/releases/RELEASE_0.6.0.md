# StrimKeep 0.6.0：工作台、直接转存与同步清理

基于 0.5.8 继续改进的完整源码，包含预编译前端。保留客户端扫码、媒体分类、九项洗版规则、杜比/非杜比共存和独立播放取链。

## 本次行为

- **直接转存**：新任务不再创建 `转存任务-N`。记录接收前目标已有内容，成功后只把本次新增条目交给整理。已开始的旧任务沿用保存记录，不重复提交转存。相关目录变空后清理，仍有视频、字幕或其他内容的目录保留。
- **自动接续整理**：新配置默认开启，旧配置显式关闭则保持关闭。可在“115 账号配置 → 链接转存”开启；须先保存归档目录、TMDB 与播放地址。机器人接收权限和来源限制保留。
- **TG 分类**：海报、转存结果、STRM 汇总、STRM 明细、错误、Emby 检查、普通任务结束分别开关。重复前缀移除，回执简化，提供命令菜单。`/organize`、`/sync`、`/status`、`/help` 可直接操作或查询。无资源轮询始终只写日志，即使开启普通任务通知也不刷屏。
- **入库海报**：成功资源按作品和季分组，包含可用海报、标题年份、集数范围、分类、规格、大小和 TMDB 编号。缺失信息不伪造；长文件明细分批发送，默认关闭。
- **STRM 全量核对**：默认每次实际扫描所选源目录。改名/移动更新路径，播放基础地址变化重写 STRM，同一文件沿用播放入口。源已删除或移出所选范围，清理旧输出。确定删除时停用播放映射；仍存在但移出范围时仅移除本地输出。扫描不完整时不删除。
- **本地遗留清理**：仅清理所选同步输出子目录内没有对应源的 `.strm`，包括未登记的历史遗留 STRM。保留 NFO、图片和属于其他输出的文件，不跟随软链接清理。关闭清理开关可仅生成/更新。
- **Cron**：整理与同步独立支持间隔或五段 Cron，保存时区，拒绝无效表达式和无实际日期的配置；恢复后不补发所有错过周期。定时同步目录独立保存，不与手动目录或整理配置互相覆盖。
- **实时日志**：通过会话校验的事件流持续显示队列、扫描、识别、输出、通知进度；可搜索、筛选和暂停显示，恢复时重新载入。任务队列和历史结果集中在同页。
- **Emby 精确通知**：将实际 STRM 路径转换为 Emby 容器内路径，优先按具体文件提交更新；服务器不支持时回退扫描。沿用本批准确文件入库核实，找到同名作品不代表验证了播放。
- **六栏工作台**：媒体总览、115 账号配置、影视整理、STRM 生成、日志中心、系统设置。诊断和索引不再占侧边栏。总览实际读取 Emby 数量、最近入库和播放会话，连接不可用时明确显示状态。
- **外观与连接**：HTTP 代理用于 TMDB/TG 等服务，Emby 默认直连；深色、浅色、跟随系统，自定义背景图片地址。手机导航、表单、目录表格、洗版弹窗和日志同步适配。整理联动支持 `1.5` 秒等小数延迟。

## 保留的流程修复

日常整理/洗版无需预建完整索引，不用维护旧目录 ID 身份关联。整理前识别失败，未配置未识别目录时原位原名保留；配置后原名移入该目录，同名冲突保留原位，其他文件继续处理。已经完成的移动如实记录，不把后续输出失败误报为“从未移动”。

播放不加入后台串行队列，使用独立连接池和短时取链缓存；转存、整理、同步继续运行，不等待播放结束。网络总带宽和 115 服务端限制仍取决于真实环境。暂停、等登录或异常任务不堵住可执行任务；不确定的云端写入只核查，不盲目重复提交。

## 覆盖更新

上传压缩包到 `/vol1/1000/测试` 后执行：

```bash
cd "/vol1/1000/测试" &&
unzip -oq "StrimKeep-v0.6.0-workspace.zip" -d "StrimKeep-v0.6.0-workspace" &&
bash "/path/to/StrimKeep-v0.6.0-workspace/StrimKeep/update.sh" "/path/to/StrimKeep"
```

不先删除旧项目，不重新初始化数据。只替换发布的程序和文档，保留 `.env`、数据库、密钥、播放 Token、`data`、`strm`。源码保留旧任务兼容代码，不需要运行迁移。刷新应显示 `0.6.0`。检查容器：

```bash
cd "/path/to/StrimKeep" &&
docker compose ps &&
docker compose logs --tail=80 strimkeep
```

## 在 NAS 验证

1. 115 账号配置 → 链接转存：确认目标目录及自动整理，TG 发测试链接。目标不再添加任务文件夹，只整理本次内容；空文件夹清理，非空保留。
2. 系统设置 → Telegram 通知：关闭不需要的普通结束、文件明细，开启海报和 STRM 汇总。定时整理空目录只在日志中心出现“未发现待整理视频”。
3. STRM 生成：选择实际源目录，手动同步。改名/移动测试源后同步应更新路径；删除源后同步应清理对应 STRM；NFO/海报保留。先用少量测试资源确认选择的同步范围。
4. 设置 Cron、北京时间、`0 3 * * *`，保存后核对下次执行时间。可用 `*/5 * * * *` 验证五分钟周期。
5. Emby 挂载同一 NAS STRM 目录，映射本程序 `/strm` → Emby `/strimkeep`；保留  的 `/strm` 挂载。挂载示例见 README。
6. 后台整理时播放已有影片，确认日志中后台仍在推进；检查手机六项导航、深浅色。
