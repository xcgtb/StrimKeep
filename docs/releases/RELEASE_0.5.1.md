# StrimKeep 0.5.1 — 工作页面与操作入口整理

2026-10-24（北京时间）。包含 0.5.0 全部功能及此前回收、存续核查和空目录修复。参考用户提供的手机布局，仅重组已有功能；没有增加参考软件中的离线下载、分享转存、Cron 或其他未实现功能。

## 页面入口

| 页面 | 现有功能放在哪里 |
|---|---|
| 扫描整理 | 立即扫描并整理、自动整理开关及间隔、来源/归档/待处理目录、洗版规则、Emby 通知、重试和输出延迟 |
| STRM 同步 | 立即同步、自动同步开关及间隔、独立定时目录、手动目录、播放地址、Emby 通知 |
| 任务 | 排队和执行进度、暂停/核查继续/取消、文件及洗版详情、补齐输出、原任务空目录重试 |
| 媒体库维护 | 完整归档索引、复核周期、修正已登记动画电影分类 |
| 通知与消息 | 站内记录、Telegram 配置和测试 |
| 连接设置 | 115、TMDB、Emby、播放地址 |

手机底部固定“整理 / STRM / 任务 / 更多”。工作页顶部固定搜索及“保存修改”；常用操作展开，高级项分卡折叠并显示摘要。修改尚未保存时显示提示，离开有丢弃确认，手动执行须先保存。洗版编辑从整理页打开，单独保存规则。

整理定时只修改整理开关/间隔，同步定时只修改同步开关/间隔及定时目录，保存时重新读取其余配置再合并，保留另一类定时和索引周期。定时同步与手动目录仍独立；“使用下方手动同步目录”仅复制当次选择。原有已保存定时继续生效，更新不会重置。

## 更新

解压 `StrimKeep-v0.5.1-ui.zip`，在其中 `StrimKeep` 目录执行：

```bash
bash update.sh '/path/to/StrimKeep-v0.1.0-phase1/StrimKeep'
```

原目录仍是运行项目；保留 `.env`、账号、密钥、数据库、Token、数据及 STRM 挂载。只构建更新 strimkeep。只需这一个新包，不需要逐个安装历史包。若实际原项目路径不同，请使用真实原目录。

## 验收

1. 登录原管理入口，确认 0.5.1；手机底部可在整理、STRM、任务间切换。
2. 整理页检查原目录、九项洗版及共存设置；分别修改并保存定时间隔，切到另一页确认其配置未被覆盖。
3. 修改未保存时尝试切页，选择继续编辑和丢弃；搜索“重试”“洗版”能直接展开匹配卡片。
4. 小范围执行一次整理和同步，在任务页查看进度/步骤；既有回收、输出和播放规则不变。
5. 真实 NAS 的持续调度、重启、较大库、115/Emby 与 Infuse/Senplay 场景仍按 0.5.0 验收表继续，不能由本地浏览器结果代替。

## 本地验证结果

后端完整回归 278 项、前端 7 项设置测试及 TypeScript/Vite 构建通过。实际 Uvicorn/Worker 受控 HTTP 检查通过。Chromium 检查手动整理/同步、目录选择、定时独立合并、搜索、未保存离开确认、洗版抽屉及 375/390/768/1440 布局通过。目录选择弹窗的手机确认按钮隐藏问题已修复。脚本语法及模拟旧项目更新保留 .env、只更新 strimkeep 通过。没有连接真实 115、Emby 或 Telegram，也没有执行真实 NAS Docker 构建。
