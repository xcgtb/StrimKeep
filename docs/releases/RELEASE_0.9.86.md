# 0.9.86 片库映射与双库扫描

- 参考 1.2.12 将片库改为海报墙，显示类型、来源与缺集状态；当前页自动对照，可对当前筛选结果发起批量缺集对照。
- 详情展示网盘库与分享库逐季集号和文件，并使用 TMDB 身份查找 Emby 中对应作品。手动完结不改变真实缺集明细。
- 明确提供「扫描双库」，待核实台账列出原因和路径。存在异常时允许查看部分扫描结果，但不能据此创建删除计划。
- 用户可在核对后选择备份并修复符合条件的失效台账；本版本不会自动删除或修复该记录。

库存仍以登记的 STRM 为基础。缺集对照需要 TMDB；Emby 跳转需要已配置且可从浏览器访问的 Emby 地址。删除计划的现有快照和回收保护不变。
