# StrimKeep 0.5.7：扫码登录客户端选择

2026-10-25。基于用户重新部署的 0.5.6 完整包修改，累计包含 0.5.6 的源码与功能。

## 操作变化

1. 连接设置 → 115 网盘 → **扫码登录**，先打开独立登录弹窗，不直接创建二维码。
2. 选择 **登录客户端**。提供 Windows、macOS、Linux、网页、115/115生活/115管理手机和平板、TV、小程序及鸿蒙等客户端身份。
3. 点击 **生成二维码**。二维码区域明确显示本次登录客户端，生成和确认均使用所选身份，不再固定 Android。
4. 用手机 115 App 扫码并确认。页面自动检查状态，显示等待扫码、已扫码、成功、过期或取消；保留手动检查按钮。
5. 成功后保存 Cookie，关闭弹窗并刷新连接标记。记住上次成功扫码选择的客户端，下次仍需明确点击生成二维码。

所选客户端是本工具使用的登录身份，不要求与扫码手机的系统相同。客户端标识依据包内固定版本 p115client 的设备映射；实际账号是否允许某个客户端仍以 115 返回和 NAS 实测为准。

切换客户端会撤销旧二维码，本次不自动生成新的二维码。关闭弹窗停止检查并撤销当前扫码；已被替换或取消的在途确认结果不能覆盖已保存 Cookie。过期二维码变灰，点击重新生成即可。

手动 Cookie 登录继续保留；保存扫码结果不会清空其他连接表单尚未保存的输入。没有新增数据库迁移、依赖或目录绑定。

## 覆盖更新

把本包上传到 `/vol1/1000/测试` 后，在 SSH 执行：

```bash
cd '/vol1/1000/测试' &&
unzip -o 'StrimKeep-v0.5.7-loginclient.zip' -d 'StrimKeep-v0.5.7-loginclient' &&
bash '/path/to/StrimKeep-v0.5.7-loginclient/StrimKeep/update.sh' '/path/to/StrimKeep-v0.1.0-phase1/StrimKeep'
```

最后一个路径为用户当前运行的、包含 `.env` 的原 Compose 项目目录。更新保留 `.env`、数据库、密钥、Cookie、播放 Token 和原数据/STRM 挂载。源码文件夹名称仍叫 0.1.0 不影响实际运行版本。

发布包包含重新构建的前端，NAS 无需安装 Node/npm。更新完成后刷新浏览器，登录页和侧栏版本应为 0.5.7。仍显示旧界面时重新加载页面。
