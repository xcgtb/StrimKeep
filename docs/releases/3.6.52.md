## 3.6.52

### CI 生产模式冒烟

- 新增 `smoke` job：构建真实镜像，启动 supervisor + Web + Worker；
- 验证 `/health/ready`、`worker_heartbeat` 写入；
- 启动日志出现 `Traceback` / `database is locked` / `UNIQUE constraint` 直接失败；
- `publish` 改为依赖 `test + smoke`，不再出现“测试绿、生产模式没测”就发镜像。

### Worker 健康可见

- 心跳从裸时间戳改为 JSON：`at` / `worker_alive` / `scheduler_alive` / `lane_faults` / `closing`；
- `/health/ready` 在 Web 模式下检查心跳新鲜度 + lane 故障；
- supervisor 兼容新旧心跳格式。

### share check / rebuild 迁 Worker

- 新增 `worker_commands` 命令队列（schema migration 5）：
  - Web 提交命令，Worker 领取执行，结果写回；
  - Worker 重启时中断命令重排一次，再失败；
  - 完成记录保留 7 天后清理。
- `POST /api/v1/share/check`：Web 只提交命令，最多等 8 秒，超时返回 pending；
- `POST /api/v1/strm/rebuild` / `rollback`：Web 提交命令并等待结果；
- Worker 不可用时直接 503，不再让请求傻等 10 分钟；
- share check 进度写入 `meta.share_check_progress`，页面仍能看到进度；
- 定时 share check 也走命令队列，避免与手动检测并发。

### 验证

- 后端全量：1686 passed, 4 skipped
- 命令队列定向：6 passed
- 前端无改动
