# 0.3.0：第三阶段批量整理与归档索引

2026-10-23。依据 V1.1 第 12 节的阶段三推进：保留已验证的整理、改名、移动、STRM 链路，补齐既有归档的身份索引和跨目录冲突判断。洗版与多版本共存属于第四阶段；本版不执行回收站或永久删除。

## 本次实现

- 新增“归档索引”页面，显示已保存的 115 归档根目录，提供直接可见的“立即建立 / 刷新索引”、任务进度、暂停、核查继续和取消。
- 完整迭代读取归档根目录及所有子目录，按文件 ID 检查重复。先完成目录读取，再核实作品身份。分页、登录、网络或 TMDB 请求失败时不发布新索引，保留上次完整结果，不将未读到的文件当成被删除。
- 索引按 115 账号和归档根目录隔离。电影、剧集分别使用 media_type + TMDB ID；剧集记录季号和集数范围，支持检出合并集与单集的重叠。
- 原有 0.2.x 的已确认归档记录在账号、根目录、文件 ID、名称、大小、父目录、相对路径及可取得的 SHA1 一致时继续使用，不因展示名称截短而丢失已确认身份。
- 对未登记的旧文件，使用明确文件名季集、作品目录 TMDB ID、名称和年份与 TMDB 交叉核实；不会只凭一个文件夹 ID 就宣称已确认。无法唯一识别的条目明确标记“身份待确认”，ISO 标记“本期延期”，均保持原位置和原名称。
- 可搜索名称、相对路径或 TMDB ID，筛选已确认、待确认和延期格式，分页查看。管理 API 不返回 Cookie、Token、直链或 pickcode。
- 每轮正常扫描整理在开始修改前刷新完整归档索引。冲突检查覆盖整个所选归档，而非仅目标季目录；使用已有候选前重新读取当前文件身份及实际位置。程序成功归档的新视频立即写入索引，避免同批第二份同集被再次归档。
- 原有多待整理目录、无限层级迭代扫描、嵌套根目录去重、7+28 分类目录、未知参数省略、歧义待处理、字幕、STRM 与一次 Emby 通知继续保留。

## 保守边界

1. 同片、重叠集数保留旧资源，新文件原名转待处理；不根据质量自动淘汰。
2. 完整归档中存在身份待确认视频时，无法排除同片冲突，本版将新资源原名转待处理。应在索引页核实原因，手工纠正旧文件名称、作品/季目录或隔离无法确认的旧资源，再刷新索引；已转待处理的新文件按计划人工移回待整理后重新扫描。
3. 索引任务只读取云端及写入本地数据库，不移动、重命名、删除旧云端文件，不生成 STRM，也不通知 Emby。正常整理任务仍按明确操作执行云端修改。
4. 本版同一时间只开放一个未完成任务，索引与整理共用原后台执行器和控制接口；跨任务种类的多任务排队、定时调度与完整同步留在第五阶段，不宣称已完成。
5. 旧库媒体参数本期不批量 FFprobe，留待实际洗版前按需探测。演唱会、合拍地区、季集等不能可靠判定仍待处理，不新增未经确认的全局优先级。
6. 索引是读取时的快照，不能锁住 115 上其他客户端。已知冲突候选在决策前读回核实；发现外部改动暂停核查，不能凭历史索引删除。

## 保留最新决定

本地仍只输出 STRM 与外挂字幕，NFO 和图片由 Emby/神医助手负责。历史已有元数据保留。NFO/图片 Web 开关留待后续，没有加入本版。

沿用 0.2.2 构建修正：前端已编译随包提供，NAS Docker 不运行 Node/npm。前后端源码和锁文件保留，修改前端源码后需先重新编译发布目录。


仍使用原含 .env 的部署目录、数据根目录、STRM 根目录、账号、密钥、Cookie 和 Token。不修改 Emby/ 的容器、端口和挂载。数据库只增加 archive_snapshots、archive_entries、查询索引及 archive_schema_version=1 标记，原表结构不变；不自动备份、重建或清空数据库。

## 本轮 NAS 验收步骤

1. 更新结束确认 healthy，页面版本 0.3.0。已有目录配置应保留。
2. 打开“归档索引”，点击“立即建立 / 刷新索引”。先核对当前测试库中 18 个 STRM 所对应的云端视频是否完整列出、TMDB/季集是否正确。数量以云端归档实际视频数为准，不把本地 STRM 个数当成云端清单。
3. 确认索引没有改动已有云端名称和位置；身份待确认项查看具体原因，不按成功身份处理。
4. 使用可恢复测试副本：同片/同集放在待整理，已有版放在不同旧分类路径，执行整理后应保留旧版、新文件原名待处理；不同集应继续正常归档和生成 STRM。
5. 在索引读取时暂停、继续或重启容器，确认保留上份完整索引、未完成任务恢复；登录/分页读取失败不清理任何媒体或本地文件。
6. Emby 的引用路径沿用现有地区目录，索引不会改写或清理插件的 NFO、图片。

## 验证范围

本地回归覆盖已有整理链路、真实 SDK 请求格式、索引快照失败保护、账户/根目录/电影剧集空间隔离、跨旧分类冲突、同批去重、外部移动后核查、后台 API 与分页脱敏、1100 层目录及重启恢复。实际 115 和 NAS Docker 运行结果仍需本轮验收。
