## 3.6.54

### 备份恢复可演练

- 新增 `backup.py`：
  - `create_backup(store)`：VACUUM INTO + master.key + manifest（size/SHA-256）；
  - `restore_backup(zip, target, force=False)`：
    - 先校验每个文件的 SHA-256，再写目标；
    - 目标已有 `state.db` 时默认拒绝覆盖；
    - 恢复后跑 `PRAGMA integrity_check`，并检查 `meta/settings/organize_jobs/organize_items` 是否存在；
  - 提供 `python -m strimkeep.backup <zip> <target>` 命令行入口。
- `/api/v1/system/backup` 改为复用 `create_backup`，接口与恢复演练走同一套代码。

### 跨进程写重试

- SQLite `busy_timeout` 从 5 秒提高到 15 秒；
- `Store.set_meta` / `set_many` / `event` 遇到 `database is locked` / `busy` 时指数退避重试 5 次；
- 降低 Web 与 Worker 同时写 WAL 库时的偶发失败。
