## 3.6.93

### 资源接入收件箱

- 新增「资源接入」页面：手动粘贴、RSS、Webhook 先进入持久化收件箱，再复用现有转存/离线/整理链路。
- 支持 115 分享、磁力、ED2K、HTTP/HTTPS/FTP 直链；按分享码、磁力 hash、ED2K hash、URL 指纹去重。
- 新增状态流转：待处理、已入队、重复、待核查、失败、已跳过；失败可重试，已入队不会重复提交。
- 新增 RSS 2.0 / Atom 订阅：定时拉取、包含/排除关键词、独立落点、落盘后整理开关、ETag/Last-Modified。
- 新增签名 Webhook：Prowlarr、下载器或自建脚本可推送 JSON/文本，令牌错误返回 404，请求体上限 1 MB。
- Worker 统一消费收件箱；Web 请求只落库，不在 HTTP 请求里等待 115。
- 不抓取资源站 HTML，不绕过登录/验证码；外部资源搜索仍走已有 OpenAPI 配置。
