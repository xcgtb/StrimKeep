## 3.6.51

### 工程化：分级监督 / 优先级队列 / 租约超时

- supervisor 改为**分级监督**：Web / Worker 任一进程退出后独立重启（指数退避 2s→60s），不再一个挂就把整个容器杀掉；
- Worker 心跳超过 45s 未更新时单独重启 Worker；Web `/health/live` 不受影响，`/health/ready` 降级为 503；
- DbWorker 拆成**双优先级池**：
  - interactive：3 线程 / 容量 24（页面请求：`/tasks`、`/logs`、`/logs/export`）；
  - background：2 线程 / 容量 32（SSE 重建 / 定时扫描）；
  - 一个池过载不影响另一个池。
- 新增任务租约超时：Worker 每 2 分钟把超过 30 分钟仍 running 的任务转 `needs_review`，不自动重放，避免不确定远端写入被重复执行。

### 双库治理文案清晰化

- 「残次品-删本地/删分享」改为带具体原因：
  - `缺集残次-删本地：缺失前序 (缺 E01) 且 中间断层 (缺 E03，疑似被和谐)`
  - `缺集残次-删分享：中间断层 (缺 E59，疑似被和谐)`
- 前端单库清理提示同步写明：前序缺失 / 中间断层 / 具体缺哪些集。
