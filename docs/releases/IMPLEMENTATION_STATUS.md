当前验收次序见 RELEASE_0.4.5.md 和 ACCEPTANCE.md；旧 release 文档保留历史设计。 urllib3_future 可能在解释器退出时产生清理警告；测试结果与退出码正常不代表 NAS 真实接口已通过。
