## 模板使用

我的网盘→影视整理→识别与自定义命名：选择自定义模板。

| 对象 | 例子 |
| --- | --- |
| 作品目录 | `{title} ({year}) {{tmdb-{tmdb_id}}}` |
| 季目录 | `Season{season:02d}` |
| 电影文件 | `{title}.{year}.{resolution}.{source}.{codec}{ext}` |
| 剧集文件 | `{title}.{year}.S{season:02d}E{episode:02d}{ext}` |

结果例子：`剧集/中国大陆/2026/金色 (2026) {tmdb-真实ID}/Season01/金色.2026.S01E01.mkv`。名称与编号由真实TMDB核验产生，试算里的123456只是格式示例。

允许title/original_title/year/tmdb_id/season/episode/episode_title/resolution/source/codec/video_codec/audio_codec/dynamic_range/fps/bitdepth/release_group/ext/original_name/category/region；02、02d、03、03d仅用于季集数字。禁止表达式、属性访问、任意格式宽度、目录穿越和转换视频容器，文件模板必须含ext。缺少规格不会编造信息。当前规格仍来自文件名，尚未加入ffprobe。

试算只展示格式，不保存配置、不请求TMDB、不操作115。保存后再识别预览。旧计划的命名/分类配置不一致时须重新预览。关闭规范重命名后保留原视频文件名，目录仍可按分类归档。

## 分类使用

打开分类归档，勾选所需类别，可选地区/年份。五类默认已选，但分类总开关默认关闭。关闭时沿用原电影/电视剧目录名称；打开后剧集使用「剧集」。

动漫/纪录片/综艺依据TMDB题材判定；儿童节目可识别TMDB Kids。演唱会不凭Music类型自动判定，需在修正作品处手动指定。自定义分类每行一个，不能重复或含路径。选择手动分类后搜索并点击TMDB作品，再重新预览。

「一次创建所选分类」先保存当前配置，再确认目标归档目录，排队创建并回验真实目录ID。不会生成影片或STRM。任务历史中显示目录名与ID。

## 未识别归档使用

先在文件管理选择未识别目录，再打开影视整理中的对应开关。预览会区分可整理、移入未识别和待修正。

只有语义识别失败（候选不唯一、季集不明确等）进入该流程；TMDB连接/响应失败、密钥缺失、模板或目录配置错误、已登记播放引用等不自动移动。未识别目录不与归档根相同。

执行时保留视频原名及明确关联字幕/元数据，按原父目录ID分组，例如 `未识别/来源-原父目录ID/原视频名.mkv`，避免不同来源的同名剧集混在一起。完整核验文件后移动，不下载视频、不生成该作品STRM。任务历史显示已移入未识别；后续可从此目录选为来源，手动修正再整理。
