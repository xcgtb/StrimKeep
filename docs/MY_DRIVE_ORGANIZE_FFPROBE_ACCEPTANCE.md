## 如何使用

1. 登录已有 Cookie 账号，选择来源与归档目录。
2. 整理页开启分类归档、地区二次分类，地区模式选“地区归组”。国家名称模式保留，升级不会改写旧配置。
3. 默认国产为 CN/HK/TW，日韩为 JP/KR，欧美含美国、加拿大、常用欧洲国家、澳大利亚和新西兰。可修改组名、国家代码，添加/移除组；多国合拍按顺序取首个命中组，未匹配归入“其他+分类”。单独配置韩国/KR 可生成韩国电影、韩国剧集。
4. 需要时开启动画电影目录。可提前“一次创建分类与地区目录”，也可识别成功后按需创建。
5. 开启“ffprobe 媒体信息提取”，检查“ffprobe 已就绪”。默认失败保留源文件、跳过该项；可明确选择回退文件名解析。
6. 选择自定义模板，点击“填入完整媒体信息模板”，调整字段、试算并保存。试算是格式示例，不查询 TMDB/视频、不保存设置。
7. 识别并预览最终目录、文件名与媒体信息来源，再确认执行。更改命名、分类、探测配置须重新预览。

| 内容 | 归档结构（作品 ID 来自真实 TMDB） |
| --- | --- |
| 国产电影 | 影视媒体库/电影/国产电影/片名 (年份) [tmdb-作品ID]/视频 |
| 欧美剧集 | 影视媒体库/剧集/欧美剧集/剧名 (年份) [tmdb-作品ID]/Season 01/剧名.年份.S01E01.…mkv |
| 动画电影 | 影视媒体库/电影/动画电影/片名 (年份) [tmdb-作品ID]/视频 |
| 日韩动漫剧集 | 影视媒体库/动漫/日韩动漫/剧名 (年份) [tmdb-作品ID]/Season 01/视频 |

后续转存沿用相同归档根目录和分类/命名设置，逐层复用已有目录 ID。第 2 集进入原 Season 01，第 2 季只新增 Season 02。现有同名分类目录可以复用；同名文件冲突保留源文件并提示，不自动覆盖/洗版。改变地区/目录模板会改变输出路径，不自动迁移旧片库。地区规则应用于所有选中的分类，可能创建截图中尚未出现的地区目录。

## 实测与命名边界

- 先核实作品身份再提取视频，不使用 ffprobe 猜测 TMDB。
- 读取实际宽高、分辨率档位、视频/音频编码、帧率、色深、音频声道数/布局、时长，以及流内可确认的 DV/HDR10+/HDR10/HLG/SDR；没有证据时不编造。有些帧级 HDR 信息不能保证识别。
- 宽屏裁切 3840×1600 归为 2160p，真实宽高另存；已确认隔行流使用 i 后缀。
- WEB-DL/WEBRip、发布组仍来自文件名。不从 ffprobe 推断资源平台、Atmos、发布组，也未实现 AI、八维洗版或杜比多版本共存。
- 新字段 `{width}`、`{height}`、`{audio_channels}`、`{audio_layout}`、`{duration}`（秒）；原分辨率/编码/动态范围/帧率/色深字段优先用已确认实测值，未知字段保留可用文件名解析值。
- 重命名关闭保留视频原名，仍可记录实测信息。明确关联字幕跟随视频归档和改名，STRM 与最终文件名一致。
- 网络/工具错误默认跳过，不误移到未识别目录；明确回退时预览与历史显示提示。身份冲突即使选择回退仍跳过。

## 依赖、读取与缓存

Docker 增加 Debian `ffmpeg` 包提供 ffprobe，Python 依赖保持不变。无需 AppID、额外服务端口/容器或 CD2 原片路径；裸源码运行需安装 ffprobe。设置接口返回可用性标记。

Python 持有临时直链及必要 Cookie/UA/Referer，ffprobe 仅取得随机令牌的回环地址，凭据不进入子进程参数、命名或缓存。只接受认可的 115 CDN/HTTPS/公开 DNS 地址，不跟随上游重定向，校验精确 Range 和总大小。单次片段最多 8 MiB，总读取预算 32 MiB，ffprobe 子进程限时 30 秒；获取直链、DNS 另有网络耗时。不下载完整大视频、不转码。超限或不支持随机读取时按失败策略处理；ISO 等光盘结构不承诺探测。

最多两个并发探测；原 SQLite 新增 `cloud_media_probes`，按账号、文件 ID、大小、SHA1 和解析版本缓存。相同指纹改名/移动后复用，指纹变化重提，无 SHA1 不复用；断开账号清理缓存。缓存不含 URL、Cookie 或 ffprobe 原始日志。
