基线：`xcgtb/StrimKeep` 2026-10-14 `6da8a83`（v1.3.1）。这是一份可覆盖、需要执行一次安装脚本的**源码补丁**，不是已经构建好的 Docker 镜像，不移动 `latest` 或旧 Tag。

## 本次包含

- 重新组织「115 媒体工作台」的概览、账号选择、七个功能入口；复用现有深浅主题，不改整个站点风格。
- 工作台总览卡显示**保存的账号数**、队列中待处理任务、最近最多 100 条播放引用、最近任务状态；卡片数字来自现有 API，不伪装为实时总数。
- 用独立、适配手机的 115 文件夹选择弹窗替代手填 CID 入口，支持进入/返回、分页、刷新、确认；对应扫描来源、整理目录、转存目录。
- 给原有文件列表、分享转存和任务列表增加适配布局；后端 API、任务队列、源码业务核心不变。
- 同一账号才能确认选择；读取晚到结果不能覆盖下一次选择；账号切换会阻止误选旧账号目录。选中的来源与归档不能同一目录、归档不能位于来源子目录内。仅选目录不发起远程写入。

## 安装（只操作 Git 工作区）

1. 确认 Git 主分支工作区为 v1.3.1（`git status --short`，有私人改动先备份）。
2. 将 ZIP 解压并覆盖到 `/vol1/1000/git/StrimKeep/`（ZIP 根直接是 `static/`、`dev/`、`docs/`）。
3. `cd /vol1/1000/git/StrimKeep && python3 dev/tools/apply_cloud_p1.py`
4. `node --check static/js/cloud-workbench-ui.js && node dev/tools/update_frontend_asset_versions.cjs --check`
5. `node dev/tests/verify_cloud_p1_ui.cjs`；有 Node 环境时运行原前端回归 `node dev/tools/verify_frontend.cjs`。
6. 核对 `git status --short` 与 `git diff --check` 后再决定是否提交；本补丁不预设 1.4 正式 Tag。

安装脚本会核验原始 `static/js/cloud-workbench.js` 的 v1.3.1 Git blob 哈希，不一致就拒绝覆盖。重复执行不会重复注入。`static/index.html` 在安装时插入两个新增引用，按源码实际摘要刷新 `?v=` 并更新 `MANIFEST.sha256`。

## 实机测试重点

- 115 账号扫码与切换；A 账号的目录加载途中切到 B 账号，不应出现 A 的选中结果。
- 浏览真实根目录及深层目录，分页可进入，来源、归档、转存三个选择不会相互覆盖。
- 选定来源后执行整理**预览**（不要直接拿真实影视资料做第一次写入）；确认转存弹窗、任务记录仍能正常打开。
- 手机 375px 与 430px 宽度以及桌面检查：顶部导航不溢出、目录弹窗不被底部系统栏遮挡、长目录名折行。
- 暗黑/浅色主题、登录状态、反代子路径。当前前端使用原有根路径 `/api/cloud`，若部署在子路径需沿用项目现有路由策略。
