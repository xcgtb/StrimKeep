## 配置和实际操作

1. 我的网盘 → 115网盘配置：保存Cookie或扫码登录，保留客户端选择。签到和回收站仍使用各自明确保存/执行按钮。
2. 链接转存与机器人：选择或粘贴115转存、磁力、ed2k、秒传目录ID，点“保存修改”；开启并保存机器人接收。Bot Token、白名单和通知目标复用规则设置。
3. 115频道监控：先登录Telegram用户会话；填写频道，默认20条、300秒，选择该频道保存目录，过滤留空即不限作品，点“保存修改”。其他用户会话没有权限读取的频道不可读取。旧的Bot管理员新消息模式保留，必须明确选择。
4. 影视整理：选择来源、归档和可选未识别目录，保存。多个接收目录在“接收目录定时整理”默认勾选并按ID去重；确认勾选范围和扫描时间后保存启用，之后定时整理从这些目录移动归档。已存在的定时任务不会因新增频道而暗中改变，新增后需保存一次接收目录定时整理。
5. 配置命名模板、ffprobe、分类/地区归组、过滤与八维；保存整理配置。可选联动STRM，操作间隔默认1.5秒；STRM额外等待可填0或小数秒。分类按需创建并复用原目录。
6. STRM生成：保存STRM扫描来源，配置输出目录/播放地址。Emby与播放：配置独立连接、API Key及Emby容器内的STRM根目录映射，保存并测试连接。打开所需细分通知及通知总开关。
7. 直接发分享链接给白名单机器人后，会排队转存；频道命中则排队转存到该频道专属目录。定时整理扫描这些来源后，识别、改名、移动、生成STRM，逐路径通知Emby；确认入库后再发入库海报。播放器使用既有Emby库和302播放入口。
8. `/strm 115分享链接` 或 `/create_115share_strm 115分享链接` 只生成分享库，不转存；分享取消或失效后播放失效，不能保证对方长期保留分享。

转存仍保留原独立任务子目录和接收回执，位于用户指定的保存目录之下；定时整理递归扫描，无需手动选择这些子目录。不会通过“请求被接受”推断远端写入或Emby已完成。

## 飞牛下一阶段验收

| 步骤 | 核对点 |
| --- | --- |
| 目录选择 | 先选一个测试目录，未点保存前刷新仍是旧值；保存后名称和完整ID立即显示，再刷新仍保持 |
| 机器人普通接收 | 发一个小分享，普通转存目录下出现对应任务内容，日志有排队、转存及回执；重复提交同一Web请求不会创建重复任务 |
| 频道 | 新建测试规则，20条/300秒、过滤空、专属目录；检查首次回读和下一轮仅新增消息，和普通机器人目录互不混用 |
| 定时整理 | 勾选该频道及接收来源，保存开启；确认归档类型/地区目录复用、ffprobe值、命名和旧源安全边界 |
| STRM/Emby | 开启联动后确认NAS文件、逐路径通知、等待/确认状态；收到海报检查来源、季集、大小和影号；从实际播放器验证能播/拖动 |
| 分享STRM | 用免转存命令，确认115未产生转存，分享库文件及播放可用；失效分享出现明确错误 |
| 停止/重启 | 停止后新视频不再整理，关联定时任务暂停；重启后回执和延时STRM仍保留，不重发未知云写入 |
