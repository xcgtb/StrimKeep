# Telegram 公开频道免登录抓取（public_web）

基线 StrimKeep **v1.5.21**。此为新增的可选频道读取方式，既不需要 Telegram 用户 API ID/Hash，也不要求 Bot 管理员权限。**这不是 Telegram 官方稳定消息 API**；仅在频道允许公开网页预览时工作。

## 配置步骤

1. 添加频道，地址如 `https://t.me/example_channel`；选择公开网页、300 秒、首次历史20条。
2. 明确选择转存、分享 STRM 或万能转发；转存才需要保存目录，生成分享 STRM 需要分享库输出与播放配置。
3. 点击公开网页只读抓取测试，核对消息文字和链接。首次0条表示不回补历史。
4. 保存并启用；“匹配消息后自动处理”关闭时仅记录消息。先小范围验证再开启。
5. 频道卡片展示最近成功、检查数量、失败次数、下次检查与游标；失败阶段见接收历史。

## 技术边界

- 使用标准库 HTMLParser 和现有 httpx 读取固定 `https://t.me/s/<合法用户名>`，不执行脚本、不跟随重定向。
- 不支持私人频道和邀请链接；网络失败、429、非 HTML、超限、时间标签异常、分页断档均保留游标并退避，不绕过登录/访问挑战。
- 单轮最多10页/200条，最多2MiB/页；超限明确报警，不默默跳到最新。高流量或公开预览缺失的频道应改用有权限的用户会话。网页编辑/删除、隐藏媒体及网页结构变化都可能造成不可读，不保证完整性和实时性。
- 收件箱与游标在同一 SQLite 事务提交，账号/规则/游标变化使旧读取结果作废；失败状态回写同样核验配置。
- 转存和分享 STRM 只处理合法115分享；万能转发可按筛选处理普通文字、说明或其他链接。Telegram 预览未暴露的资源无法读取。
- 频道转存只保存接收目录，影视整理由独立自动化运行。已有质量选版、残次品清理及跨库治理不变。
