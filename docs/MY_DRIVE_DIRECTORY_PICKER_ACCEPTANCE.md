# 我的网盘：横向导航与原地选目录

## 当前变化

| 位置 | 原来 | 本批效果 |
| --- | --- | --- |
| 手机我的网盘导航 | 下拉列表，展开后才能切换 | 直接显示横向功能按钮，左右滑动查看，点击切换；桌面保留左侧栏 |
| 影视整理四类目录 | 跳到文件管理，再设置当前目录用途 | 在扫描来源、整理归档、转存、未识别字段旁点击“选择目录”，原地浏览 115 并保存 |
| 分享转存、STRM 页 | 依赖文件管理设置 | 分别提供选择转存目录、选择来源目录按钮，与整理页共用账号配置 |

沿用主题变量、背景和按钮样式；不修改主题颜色，不增加依赖和部署配置，不改变整理、转存与删除策略。

## 使用

选择当前 115 账号，在影视整理点击对应字段旁的“选择目录”。选择器从根目录开始，仅列出子目录；点击目录进入，用根目录、上级目录、上一页、下一页浏览。进入需要的目录后，点击“选择当前目录并保存”。保存核实成功后自动关闭，原页面显示名称和 ID。

每次只保存一个目录角色，其他角色保留。选择根目录时保存 ID `0`。115 返回的文件和目录混合分页，界面隐藏文件但仍保留分页，不能把“当前页无子目录”误认为后面也没有目录。长目录 ID 全程按字符串传递。

目录保存独立于命名与分类保存。改目录后重新预览整理，再确认执行；已保存的自动任务保留其创建时的目录，不随此选择器改动，如需变更应重新创建自动任务。

## 失败和并发

- 未加载账号目录配置时不能选择；读取中或读取失败时不能保存当前目录，提供重试。
- 取消或按 Escape 不提交保存；保存请求进行中禁止重复提交及关闭弹窗。
- 保存由已有后端核实实际目录、账号凭证和配置版本，来源与归档相同仍拒绝。
- 配置冲突不会自动覆盖，需手动刷新目录配置、核对后重试。网络结果不明可刷新配置核对。
- 切换账号会关闭选择器；旧浏览和保存返回不能改写新账号页面。已向服务器提交的旧账号保存仍可能完成，切换账号不等于撤销请求。
