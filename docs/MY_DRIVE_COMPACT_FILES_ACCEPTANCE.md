## 本批行为

| 页面 | 调整后如何使用 |
| --- | --- |
| 影视整理 / 八维策略 | 默认只显示八个紧凑卡片。开关控制参与比较，箭头调整比较顺序；“设置顺序”展开该维度的档位列表，按箭头调整；未识别固定最后。 |
| 发布组策略 | “设置列表”展开，逐项添加、删除、排序；列表开合不进入保存数据。 |
| 文件管理 | 显示目录、视频、字幕及其他文件。目录点开读取内容，文件显示类型、大小、完整ID。根目录翻页，子目录“加载更多”；失败可重试，已成功的页保留。 |
| 整理/STRM定时任务 | 名称由来源目录自动生成，无需再填写。既有非空名称保留，保存的Cron、开关与后端API不变。 |
| 频道监控 / Emby连接 | 新频道用地址生成规则名，新Emby连接用URL生成名称；原有记录名称保留，不增加必填步骤。 |
| 配置工具条 | 保留顶部明确“保存修改”；重复整理保存入口隐藏；展开、收起和日志放入“更多”。仍按主侧栏的垂直子菜单切换页面。 |

文件管理展示所有文件，目录选择器仅展示目录：这是两个不同用途的入口。文件浏览不会触发整理、转存、删除或修改目录配置。更改八维后仍需点顶部“保存修改”才生效。

原七维治理、八维后端比较和执行、Cookie登录、ffprobe、分类、TG/频道接收、实时日志、STRM与Emby联动均保留；本批没有新增自建分享后删除临时源。

## 飞牛测试步骤

1. 打开文件管理：应能看到根目录文件；展开含视频和字幕的文件夹，确认名称、大小和ID。超过100项的子目录点击“加载更多”。
2. 整理 / 洗版策略：确认初始没有大片文本框；展开一个维度，调整顺序并保存，刷新后核实顺序和开关。
3. 发布组新增一项、排序、保存、刷新；与原治理页面对比密度和手机触摸使用感。
4. 新建频道规则、Emby连接、整理和STRM定时任务，无需填写名称；保存后核实列表中可辨认对应地址或来源。
5. 按此前闭环验收继续测试真实TG链接接收 → 指定目录 → 定时整理 → 改名归档 → STRM → Emby确认 → 播放与通知。
