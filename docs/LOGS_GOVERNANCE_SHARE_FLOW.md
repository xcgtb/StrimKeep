# 日志、来源绑定与分享操作改造（未发布）

## 怎么使用

### 分享直接生成 STRM

入口：我的网盘 → 媒体库 → 分享 STRM。

1. 粘贴分享链接、按需填提取码，点击“读取分享内容”。
2. 勾选视频或目录，点击“识别所选内容”。目录会在后端递归识别，单批最多 2000 项。
3. 核对作品和 NAS 输出路径，点击“确认生成到 NAS 分享库”。

此流程不转存、不修改对方网盘。分享失效后无法播放。分享库清理只删除 NAS 引用。

识别错了才展开“识别不对？手动选择正确作品”：选择视频 → 搜索片名 → 核对年份点选 → “应用修正，重新识别” → 核对后生成。电影不用填季集；剧集必须核实季集。切换视频/类型或修改搜索词后，旧候选不能应用。

若目的是保存到自己网盘，使用“去资源接收”；只带入链接，不自动发送转存。先核对保存目录，再确认转存，是否整理由该页开关控制。这两条流程不混用。

### 自生成 STRM 纳入七维治理

入口：网盘设置 → 账号授权 → 已登记源文件删除。

- “将本项目 STRM 输出目录纳入七维治理”默认关闭。勾选保存后，下次治理扫描合并原 `/media` 本地/分享根与当前配置的 STRM 输出根。
- “允许通过 Cookie 删除已绑定的本地库源文件”为独立权限开关；仅扩大扫描范围并不授予源删除权限。
- 保留原七维排序、档位、平局策略、静默期及既有定时治理方式。启用范围后，既有定时治理也会按扩大后的范围生成/执行其原流程，因此启用前应检查定时设置。
- 自生成库缺失、根目录重叠或来源登记不完整时停止/跳过，不把不可读目录当空库，不按父目录兜底扩大删除范围。改变开关或输出根目录后重新扫描计划。
- 本次范围集成针对七维治理扫描/执行；没有把影视探索、片库映射等全部入口改造成多根目录。它们仍采用各自已配置的 Emby 路径映射。

## 来源身份与删除顺序

不是用 SHA1 搜索整个网盘找同内容文件。登记关系为：

`STRM 签名及内容摘要 → 播放引用 ID → 账号 UID + 115 文件 ID → 源指纹 / 已明确绑定的附属文件`

删除前复核文件 ID、父目录、名称、大小、SHA1 与账号；同内容的其他副本不受影响。同一个视频或附属文件仍被未选中的活跃引用使用时阻止源删除。跨根共享引用的部分选择会保守停止，需完整核实引用范围。

先登记删除意图，再按文件 ID 发送 Cookie 删除；得到精确不存在回执且完整父目录中确实不存在后，才允许清理 NAS STRM 并撤销播放引用。不确定的写请求不重发；已有删除记录只核验。NAS 内容在执行期间变化时保留新内容。

上游/第三方的旧 STRM 不会被扫描 SHA1 后自动补绑，继续原 CD2 挂载源删除逻辑。额外自生成根内无登记的引用不会进入 CD2 兜底。没有新增删除网盘目录、清空回收站或自动全盘重绑。

## 日志细节

原消息继续保留，新增可折叠的结构化字段：任务、动作、状态、文件 ID、源名/目标名、父目录/目标目录、SHA1、大小、NAS 路径、TMDB 季集、耗时、缓存命中及回执说明。字段按实际阶段记录，不虚构没有采集的数据。

支持模块、关键词、级别、任务编号前缀筛选，点击任务编号只看该任务。网页保留最近 500 条；SQLite 保留原有最近约 10000 条上限。下载日志包含明细。历史日志原文不变，不补造过去不存在的耗时和指纹。

Cookie、Token、API Key、签名播放 URL、分享访问码不写入新增诊断字段；未知字段和嵌套服务响应拒绝保存。

## 模板详情

“查看模板详情”按当前未保存草稿生成目录和文件规则、电影/剧集示例，完全只读。完整、简洁、原名、自定义模式分别展示；关闭重命名时显示原文件名。字段不存在时不补造。详情接口不调用 TMDB、不保存配置、不更名移动文件。

## 验证与边界

本地回归使用 SQLite、真实临时 STRM 与可控远端 fixture；浏览器检查运行生产 HTML/CSS/JS，接口及数据为演示。真实飞牛、115、Emby、TG 与生产镜像未连接，不能据此声称生产删除验收通过。此包不修改 Compose、不会自动启用新的源删除权限、不包含 data/账号资料。
