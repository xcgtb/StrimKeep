## 任务中心行为

分享免转存功能未删除，但上一版六入口导航遗漏了可见跳转。本次补回“我的网盘”侧栏、工作台快捷按钮和“资源接收 → 分享免转存”切换；选中状态归入资源接收，分享表单的三步流程与识别修正保持可用。浏览器回归通过三个实际入口点击验证，不依靠直接调用路由到达分享页。

| 场景 | 本次显示与处理 |
| --- | --- |
| 整理进度 100%，STRM 仍在排队 | 显示 STRM 后续处理中，继续轮询，不把处理项目数当作整条链路完成 |
| 父任务已结束、延时子任务未结束 | 汇总子任务的等待、成功、异常与取消数量 |
| 通知发送结果未知 | 显示待核实数量和核对提示，读取页面不会触发重发 |
| 后续生成失败、取消或停止 | 父任务进入需要处理筛选；仍可保留原始任务结果 |
| 多次打开同一任务、切换页面或账号 | 请求序号和账号上下文校验阻止旧结果覆盖 |
| 5000 个文件结果 | 页面摘要限制各组前 30 项，文件列表默认折叠，完整步骤由用户展开读取 |
| 摘要读取失败 | 保留已有任务卡片，提示重试 |
| 多账号引用列表 | SQL 按账号过滤后再分页，不从全局前 100 条中筛选 |

摘要接口 `/api/cloud/jobs` 不包含大型 result，完整结果仍由 `/api/cloud/jobs/{id}` 提供。任务筛选与统计均针对最近 50 条记录，工作台引用指标针对当前账号最近最多 100 条引用中的活动项，均不是全库总数。通知统计按发送回执条数计数，包含海报、结果和分批明细。
