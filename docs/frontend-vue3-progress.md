## 操作边界

账号切换清空目录和敏感输入、取消旧读取、使旧预览失效，晚到写入回执不覆盖新账号。写入只在显式操作后发送；删除和源治理等重要动作展示范围并要求确认，删除另要求输入准确文字。批量全选交给后端按筛选生成封存预览，不把已加载的 40 项误作全部。

异步 202 仅展示接受及任务编号，后台运行、失败、待核实、STRM 生成、扫描提交和实际入库确认分别展示。网络中断或 5xx 的写入不自动重放，当前页面锁定重复提交；按原任务核实，配置可重新读取后核对。敏感信息不写浏览器持久存储；服务文本使用 Vue 插值转义，结构化回执隐藏令牌等字段。列表使用分页或受控长度，轮询只在页面可见时运行。

## 安装与回退

包内含完整源码和预编译 `static/`；直接运行方式不需要前端工具链。更新现有部署时使用整个新 `static/`，重新构建镜像或替换源码服务的静态目录，再强制刷新浏览器。不要把源码包覆盖到运行数据或媒体目录。

后端协议与数据格式未变，代码回退可使用迁移前 Git 提交重新构建。不要在处理中的后台删除/整理任务未核实前通过重启和重复提交尝试恢复操作。源文件删除等动作的真实影响仍由现有后端规则和当次确认决定。
