## 修复的问题

1. 原来整理页混放目录、过滤、命名、分类、洗版、执行、手动修正与定时任务；输出目录和播放地址却在播放页。改为明确的模块入口，STRM 页可以直接保存输出目录与播放地址。
2. 原来直到归档文件后才检查 STRM 输出配置，可能已改名移动后生成失败。现在整理提交和任务执行前检查输出根目录存在、无符号链接且可实际写入，并检查 TMDB 和播放地址的必要配置。不会把本机配置就绪当作远端连接或实际播放成功。
3. 转存并自动整理在提交/执行前复用同一检查；纯转存不要求 TMDB 或 STRM。关闭生成的整理模式仍可执行。
4. STRM 独立扫描未设置单独来源时，改用归档目录；不再回头扫描已经移空的待整理目录。用户已保存的独立 STRM 来源仍优先。
5. 命名、输出表单首次加载后，切换网盘子页保留草稿。文件扩展名、附属文件扩展名、忽略词和自定义分类使用可增删标签，沿用既有保存字段。
6. 保存按钮统一文字对比度。复用全局移动端底部导航，不叠加第二条导航。
7. 按钮修复覆盖共享组件：移除旧保存样式中的蓝底蓝字冲突，公共 `.btn` 不再继承父级透明文字；「更多」菜单支持点外部和 Escape 收起，展开/收起操作完成后关闭菜单，避免挡住模块入口。

## 使用顺序

1. 登录 115 账号。
2. 在整理的「来源与归档」选择待整理目录、归档目录；在转存页选择分享暂存目录。选择仅回填，保存后才生效。
3. 在规则设置保存 TMDB 密钥。
4. 在「STRM 生成 → 输出与播放地址」填写本项目独立输出目录（个人 `/strm/local`，分享 `/strm/share`）和播放器能访问的服务地址。NAS 主机路径通过 Compose 挂载到该容器路径；不把不存在的根目录自动创建为假挂载。
5. 在「识别与命名」「分类目录」设置并保存规则；整理工作台可查看缺少的配置并跳转修复。
6. 分享可以仅转存，或勾选转存后整理；是否生成 STRM 采用已保存的整理联动开关。已转存内容可以从转存页立即整理。
7. 在任务页查看真实处理结果、跳过原因、待核实操作和生成路径。需要补生成时，在 STRM 页扫描归档目录。单独生成不会改名或移动网盘视频。

原七维治理、现有命名与分类算法、已保存的规则和身份核实/冲突保留机制继续使用。上游治理挂载 `/media/local`、`/media/share` 与本项目生成挂载 `./strm:/strm` 分开；新默认值为 `/strm/local`、`/strm/share`，已保存的路径不会被升级重置。
