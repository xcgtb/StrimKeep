# 总览、海报入口与规则设置整理

本补丁基于 `main` 的 `9bf10aad4f8422171fddc587c73b36b2a659d126`。检查时最高可达正式标签为 `v1.2.4`。已合并并保留 v1.2.4 的 Emby 入库事实 / TMDB 对照时间修复。本次更改记入「未发布」，不修改版本常量、不创建标签；用户正在运行的容器尚未核实。

## 总览

- 桌面主内容靠近左侧导航，增加近期入库、缺集关注、订阅与通知、快捷任务。STRM 统计与下方片库概况、内容区边界对齐，卡片自然高度，不改变现有主题色和背景。
- 近期入库取已持久化的 24 小时入库缓存，保留来源与真实季集范围；记录条数与去重集数分别表达。特别篇保留 S00，缺少季集时显示未提供。
- 追更动态取最近一次真正成功发送的订阅汇报；「最近关注」展示已启用订阅及最近通知进度，不将通知历史当作当前片库进度。
- 缺集关注取共享片库健康快照，过期时保留缓存并明确标注。未提供的待发送数量显示未知，不伪装成零。
- 总览热门电影、热门剧集海报使用影视探索相同的作品资源详情入口。近期入库等卡片只有身份唯一或已有明确 TMDB ID 时才允许跳转，避免同名作品误跳转。
- 新增动态投影只读现有缓存，不主动访问 Emby、TMDB、Telegram 或上游，也不启动额外定时扫描。持久化修订未变化时复用小型结果；前端内容未变化时保留已解码图片。

## 规则设置

- 治理规则：治理策略、画质对比、特别篇、白名单。
- 自动任务：入库监控、定时巡检。
- 服务连接：Emby、TMDB、Telegram、HTTP 代理、上游接入、界面背景。可通过分类按钮仅查看一组。
- 面板使用明确分组，不再依赖插入位置。电脑采用两列自然高度排列，手机使用单列。
- Emby、TMDB、Telegram、代理分别保存和重新读取；只提交本组字段，不覆盖其他组草稿；同一组保存期间继续编辑的字段也会保留。
- Telegram 的 Bot 状态放回 Telegram 配置卡片。上游接入和背景继续使用各自保存按钮，自动任务开关沿用即时保存，治理画质草稿继续使用原有确认流程。
- 既有 `/api/config` 部分更新接口及脱敏规则继续使用；服务配置保存后的 Bot 重载行为由原后端决定。测试 Telegram 按钮仍是用户主动发送测试消息。
