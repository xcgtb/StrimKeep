# Vue 3 十模块原型复刻（2026-10-18）

本轮是基于现有 Python / Vue 3 应用的界面复刻与功能补齐，采用用户确认的「StrimKeep 10 模块交互原型·目录流程修正版」HTML。HTML 的布局和交互作为参考，演示接口、演示成功提示及示例业务数据没有接入正式页面。

## 源码与发布状态

- 基线：GitHub main，提交 `1346cf12b3e3cd6f37edc0b26d45ca917e463582`，对应本轮使用的 `v1.5.12` 标签。
- 工作分支：`feature/prototype-vue3-v1512`，本包为基线上尚未发布的修改；不移动既有标签。
- 包内含完整后端、Vue 3 源码、依赖锁文件、Dockerfile、编译后的 static 和校验清单。前端入口仍为 `/`，使用 Hash 路由。
- 运行版本由镜像构建传入的 APP_VERSION 决定；未验证用户 NAS 当前容器，不将此源码包描述为已上线镜像。

27 个已有业务路由保留，十个主菜单下的辅助命名、规则、订阅和回执页面仍可到达。账号、删除、治理与任务操作继续使用现有 API 及确认机制。

新增后端接口仅为已认证的只读 `/api/cloud/output-directories`：只浏览允许的媒体挂载目录，不创建目录，不读取文件内容；拒绝越界路径和指向挂载外部的符号链接。目录选择只修改草稿，显式保存后才写入设置。Compose 新增宿主机路径仍需部署者添加挂载，Web 页无法代替 Docker 配置。

原型标记为「拟议」的分享库独立洗版规则尚无对应后端执行合同，本轮保留实际支持的识别、分类、命名及冲突跳过行为，没有将演示排序接成自动删除。个人库八维和跨库七维沿用各自既有引擎。

## 使用源码

源码包解压到独立目录，根目录有 Dockerfile；先核对本轮页面，再按现有项目发布流程构建新镜像。保留原部署目录、数据、数据库、密码、端口与媒体挂载。不要把包内示例部署配置直接覆盖到正在运行的实例。

包内 static 已编译，但仍需 StrimKeep 后端提供接口；不是可双击运行的离线前端。前后端应一起更新，因为本轮包含只读目录浏览接口及日志明细。
