# 文件命名和任务通知

## 上游规范与分类

按用户提供的目录与实际文件截图对齐，标准文件名保留标题区空格，媒体信息项之间用点分隔：

`片名 (年份) - 分辨率.片源.动态范围.视频编码.位深.帧率.音频 声道-发布组.扩展名`

例如在各字段均有可靠依据时：

`走私 (2023) - 2160p.BluRay REMUX.DoVi P7.H.265.10-bit.23.976fps.TrueHD 7.1-WF.mkv`

`BluRay REMUX`、`DoVi P7`、`TrueHD 7.1` 是完整信息项，内部空格保留。帧率和声道小数保持。片源与发布组由原文件名解析，优先使用 ffprobe 实测编码、位深、帧率和音频；不补造未识别的声道、杜比配置或 Atmos。ffprobe 保留 Dolby Vision profile、DTS-HD MA/HRA 等命名信息，原质量比较字段保持。

电影文件名不重复加入 TMDB 标记，作品目录统一为 `片名 (年份) {tmdb-ID}`。剧集在文件名中保留季集号，并沿用 `Season 01` 季目录。简洁模式只添加分辨率与编码，自定义模板按填写内容生成，不强制把标题空格替换成点。

视频、匹配字幕、STRM 与 NFO 使用相同文件名前缀，字幕 `.zh.srt` 等语言后缀继续保留。保留原名、关闭重命名仍按原设置执行。升级不会批量改动已归档文件。

在「影视整理 → 分类目录」点击「采用上游整理规范」，填入电影、剧集、动漫、纪录片、综艺、儿童节目、演唱会七个主分类，地区采用国产、欧美、日韩、其他分组。动画电影归入 `电影/动画电影`，例如 `剧集/日韩剧集/作品 (年份) {tmdb-ID}/Season 01`。此操作只填写表单，保存后生效，不自动创建远端目录或移动已有文件。预创建分类和实际归档仍使用同一套分类规则，已有目录按需复用。

截图同时含少量旧的方括号 TMDB 目录，现有目录不会由升级自动改名。自定义模板保留用户填写的目录括号；要在模板中输出 `{tmdb-123}`，使用 `{{tmdb-{tmdb_id}}}`。

## 输出位置

生成记录显示的是实际写入时的容器路径。旧记录 `/media/local/...` 对应原上游挂载，并不对应新建的 `./strm/local`。

使用独立挂载 `./strm:/strm:rw` 时，在「STRM 生成 → 输出与播放地址」保存个人 `/strm/local`、分享 `/strm/share`。保存后重新进入页面核对。已转存并归档的媒体可在「扫描与生成」选择归档目录补生成，不需要重新转存、移动影片。旧输出文件保留，不自动迁移或清理。

Emby 需挂载同一宿主机目录，例如 `/vol1/1000/docker/StrimKeep/strm:/strimkeep-strm:ro`，媒体库中添加 `/strimkeep-strm/local` 和 `/strimkeep-strm/share`。

## 两种通知

机器人晨报属于治理通知。网盘任务通知有独立总开关，晨报发送成功不代表 STRM 任务通知已经开启。

在「Emby 反代与播放 → 任务通知」开启网盘任务通知总开关和 STRM 同步及生成通知，点击保存。需要逐项路径时再开启 STRM 文件明细。既有开关不会因升级自动打开。

整理完成海报不依赖 Emby 连接：网盘任务通知总开关和「整理完成海报」开启后，在作品移动、命名及附属文件操作核实，且该作品 STRM 发布收尾后发送；延时生成也等待本批延时任务收尾。随后按 STRM 通知和文件明细开关发送生成结果；不因 Emby 扫描完成再重复发海报。需要网页显示入库状态时，在「Emby 入库连接」填写服务地址、API Key、实际 Emby 路径并启用连接。当前挂载示例填写个人 `/strimkeep-strm/local`、分享 `/strimkeep-strm/share`。还需启用生成后请求 Emby 扫描，并让 Emby 的媒体库包含这些目录。

STRM 生成成功、Emby 接受扫描请求与 Emby 实际确认入库是不同进度。只有路径、TMDB、季集均通过核验才在网页显示已入库；可查看实际入库确认记录。新开关影响后续事件，不自动重发历史通知。

## 验证范围

使用远端接口替身验证命名、SQLite 记录、本地实际文件生成、输出目录切换和通知条件；真实 Chromium 验证手机与桌面配置保存。未宣称已连接真实 115、飞牛、Emby 或向真实 Telegram 发送测试消息。
