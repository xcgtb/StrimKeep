## 关键场景的结果

- 主视频或登记字幕身份发生变化：不发删除请求，不删 STRM，不回退名称匹配。
- 官方删除超时：保存 unknown 回执、保留 STRM；后续只有读查询。文件仍可见时不重发。
- 主视频已确认删除、字幕结果不明：准确报告已确认的主视频数量，保留 STRM。恢复时不会重复计数或重复提交主视频删除。
- 云端已确认删除、本地清理失败：保留绑定和 STRM，可再次预览/清理；不会重新删除云端。
- 本地 STRM 已清理、最后的状态记录失败：按实际删除数量报告，通过只读复核原 ID 和本地缺失恢复最终状态。
- STRM 生成完成但激活记录中断：保留待核实记录，核对 URL 令牌、文件指纹和所有源 ID 后可激活。
- 完成删除后，同一路径绑定新视频：使用新绑定和新回执，历史证据保留。
- 旧 STRM 接管：唯一显式提取码可以核验；路径片段、文件名、多个提取码和无效 URL 均拒绝猜测。
- 分享库：只清理本地 STRM，不调用任何 115 源删除。
- 按 ID 整理：预览不写云端；源/目录/绑定归属在预览后变化、目标重名或分页截断均停止。官方移动/改名保存逐步意图，超时不重发；复核后只继续未提交步骤，未知整理阻止同一源治理删除。
- 独立转存：同账号官方 Token 与辅助 Cookie 身份核验；预览不写云端；确认后在独立暂存目录接收，官方接口核验完整对象集与 SHA1。分享来源 `100/101` 对应自有目标 `600/601`，同名已有对象 `10` 不参与交接，治理只删除 `600/601`。
- 来源持久登记：转存历史裁剪后保留视频及关联文件关系；生成 STRM、接管与整理继承已捕获关系，拒绝跨转存组关联混入，禁止将已知字幕登记为主视频。数据库写入失败后只读复核可幂等补齐登记。
- 转存未知：目录创建或分享接收的意图先落盘；超时不重发；结果为空、部分完成或有外来对象时保留 unknown。新建预览不能绕过未确认任务；尚未提交的步骤核验后才能确认继续。
- 授权交换/刷新结果未知：不会再次消费同一个交换或刷新凭据；账号需要重新授权，或只重试未完成的身份读取。
- 302：核对返回直链文件 ID，沿用播放器 User-Agent；额外 Cookie 要求不伪装为可播放结果。
