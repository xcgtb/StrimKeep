# TgtoDrive OpenAPI 接入（第一版）

基于 StrimKeep v1.2.1 / b12563f；实现依据为用户提供的 TgtoDrive OpenAPI 3.0.3、规范版本 1.0.0。
这是按需业务接入，不改变七维治理、源文件删除、分享库删除、订阅或 Emby 实时同步。

## 使用

1. 上游实用工具 → OpenAPI 创建一个访问令牌。
2. StrimKeep 规则设置 → 服务连接 → TgtoDrive 上游接入：填写上游地址和令牌，测试连接、启用并保存。
   地址必须从 StrimKeep 容器可达；有反向代理子路径时填写完整前缀。令牌仅服务端保存，输入框重新加载时留空。
   令牌留空保留；换地址必须输入新令牌。停用后可勾选清除令牌并保存。默认转存积分上限为 0。
3. 影视探索电影 / 剧集卡片点击找资源；片库映射详情点击找资源 / 补集。
4. 剧集可按季、集查询（填写集时必须指定季）；目标网盘标识默认 115，需与上游实际标识一致。
   选择资源前核对年份、季集和版本；整季资源不会因填写某一集而保证只转存这一集。
5. 确认后提交转存，保存的目标目录、整理规则和 STRM 生成配置均沿用上游设置。
   查看转存任务与整理记录；上游已接收请求不代表网盘转存、整理或 Emby 入库已经完成。
6. 完成 STRM 生成后，原 Emby 回调更新总览、探索角标、片库映射；只有已订阅的作品按原链路通知。

## 接口与返回适配

| 操作 | TgtoDrive 接口 | 适配范围 |
| --- | --- | --- |
| 测试、能力检查 | GET /api/openapi/spec | 检查 paths 中的实际方法；不会读取全局 env / 云盘凭据 |
| 资源搜索 | POST /api/media/resources/search | title、media_type、tmdb_id、year、season、episode |
| 手动转存 | POST /api/media/resources/transfer | 源返回的 source + slug / share_url 或显式 candidate_item_id；目标 provider、enforce_points_limit、max_points |
| 整理来源列表 | GET /api/organize-history | keyword、page、limit=20 |
| 整理详情 | GET /api/organize-history/detail | record_id；白名单字段输出 |

搜索与列表支持直接数组，以及 resources / results / items / list（整理还支持 records / history）数组、data 包装。
搜索每次最多展示 50 个候选。资源必须带明确的 source + slug / share_url 或 candidate_item_id 才能转存；不会把普通 id 猜成转存 ID。
详情支持顶层对象、data 对象、data.record；只输出名称、年份、TMDB、季集、来源、状态、文件名与路径等明确字段。
按片名找到的整理记录只供核查，未与本地 STRM 精确绑定，不能作为自动删除依据。

上游文档多数字段标记 inferred / generic，没有完整响应模型。上述结构是适配边界，自动测试使用人工合同样例，**没有真实上游响应验收**。
不识别的返回会报告“暂不兼容”，不会变成无资源或零记录；需要实际脱敏响应后补充适配。
规范参数不能证明上游积分限制在所有来源均生效，付费来源上线前应在真实服务验证限制。
本版不提供上游自动获取订阅、自动缺集转存、源文件 API 删除、自动触发全网盘 STRM 同步或上游主动推送。

## 资源与任务限制

- 未启用默认不连接；进入探索、渲染海报、Emby 同步均不触发上游请求。
- 只允许固定业务路由，没有任意 URL / 接口代理；采用现有 Web 鉴权与同源保护。
- 上游最多两个并发网络请求，单请求 socket 超时 20 秒，响应最多 2 MiB；服务请求绕开外部代理，不跟随重定向。
- 能力检查按需缓存五分钟，不是定时查询。转存仅一个后台提交线程，不占原通知、治理任务锁。
- 候选身份仅在服务端内存保存：十分钟失效，最多 500 条；连接或令牌变化后失效。上游目标标识不推测，不识别时由上游拒绝。
- SQLite 保存最多 100 条转存请求记录；同请求编号及同资源 / 同目标 / 同连接去重。超时、断连、模糊响应不自动重试。
- 重启后残留“正在提交”变为“结果待核实”，不自动重复写入。用户必须先查看上游历史，明确清除记录后才能重新提交同资源。
- 任务查询只发生在打开任务视图且提交中的场景；关闭或切换视图停止后续查询。这是查询我们自己的任务，不是轮询上游入库。
- 默认不生成新 JSON 状态文件，任务继续复用 SQLite state_store；不改媒体或 /data 原有事实文档。

## 验收

新增测试覆盖本地 HTTP 鉴权、重定向凭据保护、响应限额、地址变更令牌、并发限额、候选过期、确认取消、持久化去重、超时与重启结果、详情字段保护及前端旧响应隔离。
需在飞牛继续验证真实上游：连接测试 → 一次资源搜索 → 核对候选 → 手动转存 → 上游历史 → STRM 生成 → Emby 回调与现有已订阅通知。
Docker 构建、真实 TgtoDrive API、积分限制、NAS 文件系统及 Safari 布局未由自动测试验证。

## 资源详情界面补充（1.2.2 后的未发布补丁）

资源入口复用已有作品海报、年份、评分及已知双库数量。点击入口后自动执行一次资源搜索；不在海报网格启动上游请求，转存目标读取在搜索后执行，避免目标列表阻塞首批资源。

资源来源、网盘、分辨率、视频类型、视频效果、发布组的组合筛选与数量基于实际返回的候选；最多显示 50 条，并提示截断。筛选为本地筛选，不宣称是上游全部资源总数，不自行推断未知技术字段。切换筛选保留原候选索引与服务端句柄。

`GET /api/upstream/providers` 只读取上游 `/api/media/providers` 中明确命名的 `transfer_targets` / `transfer_providers` / `targets` / `netdisk_providers` 转存目标组；不把资源来源当作目标。响应模型未知时保留高级设置手填标识，并显示原因。实际 TgtoDrive 响应结构仍需验收或提供脱敏 JSON 扩展适配。

本次没有新增源文件删除、离线下载、自动订阅转存或未确认的远端进度。已有任务页显示提交状态，实际转存与 STRM 生成仍在上游核实，入库由 Emby 回调确认。

## 资源详情展示

影视探索点击海报打开资源详情，订阅按钮保持独立。候选公开字段支持发布者、评阅数量、字幕、校验、备注与规格；只展示上游实际返回的值，缺失发布者显示“上游未提供”。OpenAPI 未定义候选响应字段，实际字段名称可能随上游版本变化；未知字段不推断、不透传。零积分和零评阅数正常显示。桌面自适应多列、手机单列。

积分与解锁信息分开展示：points / unlock_points 等表示积分；is_unlocked / unlock_status 等表示当前账号解锁状态；unlock_count 等表示解锁人数。缺字段显示未知，不从零积分或他人解锁人数推断账号状态。支持 metadata / resource_info / attributes / extra / re0 中的已知公开字段，绝不透传原始对象。OpenAPI 未声明实际返回字段，别名兼容需真实响应验收。

## 资源操作与主动订阅

复制链接使用 POST /api/media/resources/copy-link（source + slug + provider）；可能触发上游扣积分，须确认。原始资源身份仅在后端保存，成功链接通过鉴权 no-store 接口返回；剪贴板被 Safari/HTTP 限制时可在链接框长按复制。

目录信息读取 GET /api/media/settings 的 media_transfer_targets。转存接口未声明单次自定义目录参数，本版不写入猜测字段或修改全局配置，仅显示已配置目录。

分享 STRM 生成暂时移除，资源卡片只保留转存和复制链接；不提供单链接命令准备，也不调用目录扫描接口。后续具备明确的单链接执行接口规范后再接入。

主动资源订阅使用 POST /api/media/subscriptions：电影/剧集 TMDB 身份、目标网盘、enabled=true；匹配规则、检查周期、积分限制与目录沿用上游配置。GET /api/media/subscriptions 和 /events 展示订阅与最近监控事件。这是上游影视资源自动订阅，不能声称已接入未公开的 Telegram 频道管理接口。

资源订阅明确成功后可登记本地入库通知；上游受理不触发入库通知，只有 Emby 缓存提交事件确认新增集数/电影版本/目标库变化后排队。当前已有内容仅登记基线，原剧集追更订阅存在时使用原通知链避免重复。通知队列上限100，最多100部登记，后台单线程发送，失败60秒后重试；不新轮询 Emby。Telegram 超时存在至少一次投递边界。需配置 Telegram 并启用入库监控、通知总开关。上游受理超时不会自动重发，也不会凭猜测登记通知。

所有新操作基于用户提供的静态规范和模拟响应验证；实际响应未定义，真实上游版本、目录结构、任务返回和资源规则须飞牛验收。
