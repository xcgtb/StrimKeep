# 盘内库存与整理预览

入口：我的网盘 → 文件管理 → 盘内库存。先选账号和扫描目录，再点击「扫描盘内库存」。扫描为只读操作，不更改 115 文件，不生成或删除 STRM。

## 看懂结果

- 一个卡片代表一个作品目录，不是去重后的作品数；同片不同版本目录会分别保留。
- 支持 `片名 (2024) [tmdb-123]` 与 `片名 {tmdb-123}`。类型按电影/剧集父目录判断，也可在单独扫描作品目录时指定。没有明确类型不会猜用电影 API；没有编号不会自动套用搜索第一条。
- 海报资料使用已有 TMDB 设置，每次最多请求 200 个不同的类型/编号组合。未配置密钥、连接失败或达到上限时仍保留目录库存，卡片明确显示待核对。电影和剧集同编号不会串海报。
- 剧集详情只列扫描到的已有季集：例如 `S00E01`、`S01E01-E03`、`S01E04E05`，或 `Season00/[01].mkv`。单独 `[01]` 没有季目录时不默认第一季。无法确定季集的视频单独计数；这里不提供整剧完整性判断。
- 卡片统计整个目录的视频数与大小，详情最多列 100 个视频、200 个季集。扫描最多 20,000 个文件、20,000 个目录；超限请选择较小目录，避免不完整结果覆盖旧库存。

## 从库存继续操作

详情可浏览实际网盘目录，或把目录带到「整理预览」「STRM 资源」。只带入本次来源，定时目录不自动改变，任务不会自动启动。整理需要先扫描预览并核对原名、目标名、归档目录；STRM 仍使用现有生成、发布、回执与受管引用清理机制。

整理预览可按待整理、已跳过、待识别筛选，输入片名或文件名查找，再通过「修正识别」调整。修改目录或识别后，重新预览再确认执行。

## 任务与更新

扫描返回持久任务，页面或任务中心可查看进度、停止。相同账号/根目录/选项已有任务时复用，不重复扫描；不同选项需等原任务结束。只有完整成功才更新该目录可见库存，失败或停止时显示上次成功结果和时间。换账号、换扫描根会查看对应结果；更新授权后需要重新扫描。扫描期间发生的网盘外部变更不属于事务快照，可完成后再扫描核对。

这版借鉴 demo 的盘内浏览和整理对照思路，沿用 StrimKeep 的任务、账号隔离及生成链路。没有引入 demo 的直接文件修改、无管理边界清理或独立服务。
