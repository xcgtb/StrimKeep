## 新接口与前端入口

所有新增接口均需现有登录鉴权；写请求沿用同源校验。

| 方法与路径 | 对应组件 |
| --- | --- |
| `GET /api/cloud/jobs/{id}/chain` | `TaskChain.vue`，任务详情和任务回执 |
| `POST /api/cloud/jobs/{id}/recovery/preview` | `TaskRecovery.vue`，需要处理的整理/流程/转存任务详情 |
| `POST /api/cloud/jobs/{id}/recovery/apply` | 恢复确认框；提交 `preview_id` 与 `confirmed: true` |
| `GET /api/overview/playback/metrics?days=7` | `PlaybackMetrics.vue`，媒体总览 |
| `POST /api/overview/playback/collection` | 播放统计采集开关，提交布尔 `enabled` |

原有 timeline 接口现查询同一任务族的最近过程记录。一次最多500个任务、300条事件；超出时展示截断提示，不把已加载子集称作整个流程完成。入库与通知通过各自真实回执统计，不凭任务接受状态判断成功。

## 恢复范围和保护

- 账号授权、命名分类规则、文件内容或位置与已记录证据不一致时，要求重新预览。
- 前端提交回执未知时提供只读核实入口，读回已有后续任务或当前采集开关后再解锁，不以重发写请求处理超时。
- 预览有效5分钟；输出地址或路径改变、原任务状态改变、账号修订变化都会阻止旧预览提交。
- 已发出的未知移动/命名请求只有在当前身份与目标状态一致时才允许继续；原位存在不能证明请求未发生。
- 重新核对已登记STRM和关联文件的内容摘要，已完成的发布不再提交；既有延时子任务继续拥有其发布范围。
- 同一原任务只创建一个恢复子任务。再次请求返回原子任务，不自动复活取消的恢复任务。
- 恢复沿用原作品/季海报发送声明；已发送、已派发但未知的声明不重新发送。后续任务可产生独立的任务结果回执。
- 空目录清理和旧源删除不作为本恢复入口的副作用；涉及洗版时使用原有专用核实继续入口。未知发布不能由记录和文件证实的，返回STRM页重新同步。
- 普通转存超时继续使用原有只读核实与继续整理接口；转存后的整理已开始并保存计划时，也可使用恢复预览。

## 播放统计口径和实际限制

采用 Emby 官方 `GET /Sessions` 数据契约：会话、用户、正在播放项目、进度 ticks、暂停和播放速度。依据：[官方 Sessions API](https://dev.emby.media/reference/RestAPI/SessionsService/getSessions.html)。

只累加相邻、同用户同影片、未暂停、同速度且进度合理前进的观测。进度跳跃或回退、停止时未观测的尾段、超过45秒的空档均不补算；倍速换算并以实测墙钟间隔为上限。重启或暂停采集后丢弃旧活跃观察，只保留汇总，不把中间空档计成观看时间。

“人数”是区间内有有效观看时间的不同Emby用户；匿名或无法建立用户身份的会话不计。播放段是连续观测到的片段，不等于一部影片完整播放次数。短于采样间隔的播放可能遗漏；暂停边界和跳跃边界采用保守口径。统计范围为系统设置的主Emby服务，使用具有会话读取权限的密钥。

没有启用之前的历史时长不从续播百分比、播放链接请求数或单次已播放标记推算。历史回填及其他播放统计插件导入未实现。图表按UTC日期展示。事件保留最近10000条，播放段保留90天，按日汇总保留365天；前端可查询7/30/90天。

115磁力/ed2k下载属于外部异步任务，接收回执不能证明下载和后续整理完成，流程会说明等待外部结果。本轮没有把不具备证据的外部下载状态自动拼接为成功。
