# StrimKeep 0.7.0 发布说明（模块精简版）

本包保留稳定底座、统一业务链路与性能优化；模块精简及升级行为见 MODULE_REMOVAL.md。

## 升级内容
- 播放地址统一为公共实现（playaddr.py），新旧 /play/{id}[/名称] 两种格式永久兼容。
- 错误按场景分级：分享/接口的"不存在"不再误判自有文件已删除；限流/登录失效
  一律等待恢复，绝不批量撤销。
- 分享 STRM：TG/Web/监控走同一管线；整理进持久化任务；洗版与转存整理同一套
  质量规则；同分享不同目录同名文件不再冲突；主动撤销的条目不会被监控复活。
- 离线下载：提交登记 → 完成核查 → 只整理本批（响应丢失不重复提交）。
- 性能：总览 15 秒缓存（绑定数据版本与 Emby 身份）、任务列表/任务 SSE 批量
  统计消除 N+1、分享播放接入优先取链通道。
- 本精简包会清理已移除模块的专属表、配置和任务；具体范围见 MODULE_REMOVAL.md。

## 兼容性
- 已有账号、其他模块配置、Token、STRM、Emby 路径映射保留。
- 同步任务产出的 STRM 会从旧格式原地更新为可读格式一次（播放身份不变），
  并触发一次 Emby 路径通知，属预期收敛。

## 交付一致性
- 版本号统一为 0.7.0（后端 `__init__`、前端 package.json、镜像 tag、
  /health/ready 返回值）。
- 运行数据（data/、config/、strm/）为挂载卷，不进入镜像；发布包不含
  数据库、密钥与会话。
- CI/GHCR：现场为单机 NAS 部署，未建流水线；源码以 git 仓库为准，
  镜像由 Dockerfile 在 NAS 本地构建（前端在镜像内编译）。
